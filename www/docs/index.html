API стану повітряних тривог

Стан тривог по областях, районах і громадах України — для пристроїв, застосунків і ботів. Дані надходять від ukrainealarm.com через webhook і звіряються з їхнім API щохвилини.

Базова адресаhttps://alerts.example.com
ФорматJSON, UTF-8; час — RFC 3339 (UTC)
Миттєві зміниServer-Sent Events: /api/v1/stream
Доступза токеном (як отримати)

Два варіанти використання:

  • API v1 — стан регіону з урахуванням ієрархії одразу «з коробки»: active / partial / none, найвищий рівень загрози, тип тривоги. Підходить для лампи, табло, бота без власної логіки.
  • Сумісний v3 — ті самі відповіді, що в api.ukrainealarm.com/api/v3. Готовій прошивці чи бібліотеці досить замінити адресу й токен.

Токен і авторизація

Кожен запит потребує токена. Токен видає власник сервера; він має вигляд ac_ + 43 символи і обмеження: дозволені регіони, ліміт запитів на хвилину, кількість одночасних потоків, термін дії, інколи — дозволені IP-адреси.

СпосібПриклад
заголовок (рекомендовано)Authorization: Bearer ac_…
як в ukrainealarmAuthorization: ac_…
окремий заголовокX-API-Key: ac_…
у адресі — лише для токенів з дозволом?token=ac_…

Токен у адресі потрапляє в журнали проміжних серверів — використовуйте його, лише коли пристрій не вміє заголовків. У браузері замість цього — сесія.

Спробувати на цій сторінці

Вставте свій токен — кнопки «Виконати» нижче надсилатимуть справжні запити з ним. Токен лишається лише в пам'яті цієї вкладки й нікуди, крім цього сервера, не передається.

Токен не задано.

Як рахується стан

Регіони — як в ukrainealarm: область (State) → район (District) → громада (Community). Тривоги оголошують на будь-якому рівні; стан регіону враховує і предків, і нащадків:

stateКоли
activeтривогу оголошено для самого регіону або будь-якого його предка (район, область)
partialтривога лише в частині вкладених регіонів (напр. в одному районі області)
noneспокій

Рівень загрози level — найвищий серед чинних: red — ракетна небезпека, yellow — загроза БпЛА, unknown — не вказано. Рівнів може бути кілька одночасно — усі вони в types.<тип>.levels.

Свіжість. Якщо сервер давно не підтверджував стан з джерелом (немає зв'язку), відповідь має "stale": true — показуйте останній відомий стан з позначкою «немає зв'язку», а не «спокій».

API v1

GET/api/v1/statusСтан регіонів

Поточний стан запитаних регіонів з урахуванням ієрархії. Для пристроїв, що опитують сервер (раз на 10–30 с у межах ліміту токена). Для миттєвої реакції — потік.

Параметри

НазваДеОпис
regionsqueryID регіонів через кому, до 64. Без параметра — регіони, закріплені за токеном. Напр. 32,4

Відповідь 200 StatusResponse

{
  "ok": true,
  "stale": false,
  "verifiedAt": "2026-11-08T13:20:05Z",
  "version": 4182,
  "regions": {
    "32": {
      "id": "32", "name": "Вінницький район", "type": "District",
      "state": "active", "level": "red", "since": "2026-11-08T13:01:10Z",
      "types": {
        "AIR": { "state": "active", "levels": ["red", "yellow"],
                 "since": "2026-11-08T13:01:10Z", "from": ["32"] }
      }
    },
    "4": {
      "id": "4", "name": "Вінницька область", "type": "State",
      "state": "partial", "level": "red",
      "types": { "AIR": { "state": "partial", "levels": ["red", "yellow"], "partial": ["32"] } }
    }
  }
}

Помилки: 400 некоректний чи невідомий регіон, 401, 403 регіон поза дозволеними, 429. Див. помилки.

GET/api/v1/streamПотік змін (SSE) — рекомендовано

Одне довге HTTPS-з'єднання (text/event-stream); зміни приходять, щойно сервер їх отримав. Скільки потоків можна тримати одночасно — задано в токені.

Параметри

НазваДеОпис
regionsqueryяк у /status

Події

eventdataКоли
snapshotStatusResponseодразу після підключення — повний стан запитаних регіонів
update{"version", "region": RegionStatus}змінився стан регіону (а не на кожну подію в країні)
meta{"stale", "verifiedAt"}змінилась свіжість даних
bye{"reason"}токен змінено, відкликано чи прострочено — сервер закриває потік
: ping—коментар кожні 15 с, щоб з'єднання не вважалось мертвим
 
retry: 2847

event: snapshot
data: {"ok":true,"stale":false,"verifiedAt":"…","version":4182,"regions":{…}}

event: update
data: {"version":4183,"region":{"id":"32","state":"none","types":{},…}}

: ping
  • Після обриву просто перепідключіться: першою прийде snapshot з актуальним станом — нічого не загубиться.
  • Якщо 45 с не надходить нічого (навіть ping) — з'єднання мертве, перепідключіться.
  • retry — рекомендована пауза перед перепідключенням, мс (1–5 с, випадкова — щоб пристрої не стукали одночасно).
  • Зміни, що сталися між двома відправками, можуть злитися в одну — ви завжди отримуєте останній стан.
GET/api/v1/regionsСписок регіонів

Усі регіони з назвами й зв'язками. Список змінюється рідко: тримайте його в кеші. Відповідь має ETag — запит з If-None-Match поверне 304 без тіла.

Відповідь 200

{
  "ok": true,
  "regions": [
    { "id": "4",    "name": "Вінницька область", "type": "State" },
    { "id": "32",   "name": "Вінницький район",  "type": "District",  "parent": "4",  "state": "4" },
    { "id": "1234", "name": "Вінницька територіальна громада", "type": "Community", "parent": "32", "state": "4" }
  ]
}

parent — безпосередній предок, state — область. Регіони тестової області мають "test": true.

GET/api/v1/meМій токен

Налаштування вашого токена й ваша адреса очима сервера — зручно для перевірки підключення.

{
  "ok": true, "id": "1a2b3c4d", "name": "Лампа кухня",
  "expires": "0001-01-01T00:00:00Z",
  "rpm": 30, "streams": 1, "streamsOpen": 1,
  "regions": ["37"], "nets": [], "allowQuery": false,
  "ip": "203.0.113.25"
}

expires = 0001-01-01… — безстроковий; порожній regions — усі регіони; порожній nets — будь-які адреси.

POST/api/v1/sessionСесія для браузера

EventSource у браузері не вміє заголовків. Сторінка один раз надсилає токен у заголовку й отримує cookie __Host-ac_session (HttpOnly, Secure, SameSite=Strict, 12 год); далі потік і запити працюють з нею, а токен не потрапляє ні в адресу, ні в журнали.

  • Лише токен у заголовку (не ?token=); запит з чужого Origin відхиляється — сесія працює лише на цьому ж сайті.
  • Сесія має ті самі обмеження, що й токен. Зміна чи відкликання токена одразу гасить усі його сесії.
  • Сесії живуть у пам'яті сервера: після його перезапуску 401 → повторіть POST.
{ "ok": true, "expires": "2026-11-09T01:20:05Z" }
await fetch("/api/v1/session", { method: "POST", headers: { Authorization: `Bearer ${token}` } });
const es = new EventSource("/api/v1/stream?regions=32");   // cookie додається сама
DELETE/api/v1/sessionЗавершити сесію

Видаляє сесію й cookie. Відповідь: {"ok": true}.

Сумісність з ukrainealarm API v3

Ті самі поля й семантика, що в https://api.ukrainealarm.com/api/v3: замініть адресу на цей сервер і токен — на свій. Повертаються лише регіони, дозволені токену. Якщо дані застаріли, відповідь має заголовок X-Data-Stale: 1. Тестова область у v3 не потрапляє.

Масив записів регіонів, де зараз є тривога. Запис регіону містить тривоги, оголошені для нього самого, його предків і вкладених регіонів — кожна зі своїм regionId (як в оригіналі).

[
  {
    "regionId": "4", "regionType": "State", "regionName": "Вінницька область",
    "lastUpdate": "2026-11-08T13:01:10Z",
    "activeAlerts": [
      { "regionId": "32", "regionType": "District", "type": "AIR",
        "lastUpdate": "2026-11-08T13:01:10Z",
        "activeAlertLevels": [ { "alertLevel": "Red", "reason": "", "createdAt": "2026-11-08T13:01:10Z" } ] }
    ]
  }
]

Масив з одного запису (як в оригіналі). Без тривоги — запис з порожнім activeAlerts.

Параметри

Помилки й ліміти

КодКолиЩо робити
400некоректний чи невідомий регіон, забагато регіонів (понад 64)виправити запит
401немає токена; невідомий, прострочений, з недозволеної адреси, у адресі без дозволуперевірити токен — причину навмисно не уточнюємо
403регіон поза дозволеними для токеназапитувати лише свої регіони
429перевищено ліміт запитів чи потоків токена; або адресу тимчасово заблоковано після невдалих спробчекати Retry-After секунд
503сервер щойно запустився або забагато потоків загаломповторити пізніше
  • Ліміт запитів — на токен, за хвилину (видно в /me, поле rpm). Потік рахується як один запит.
  • Багато невдалих спроб авторизації з однієї адреси — адресу блокують на 15 хв (усі запити → 429).
  • Затримка: сервер передає зміну за мілісекунди; сама подія від ukrainealarm приходить зазвичай за 2–10 с, зрідка до хвилини. Якщо webhook загубився, зміну підбирає щохвилинна звірка з API ukrainealarm.

Тестова область

Для перевірки пристроїв без справжньої тривоги є вигадані регіони, якими керує адміністратор: 990000 «Тестова область», 990100 і 990200 — райони, 990101, 990102 — громади.

  • Їх бачать лише токени, яким тестову область дозволено явно («усі регіони» її не включають).
  • Кожен їхній стан має "test": true; у сумісному v3 і на публічній сторінці їх немає.
  • Ієрархія та сама: тривога в тестовому районі робить його громади active, а область — partial.

# стан
curl -H "Authorization: Bearer $TOKEN" "https://alerts.example.com/api/v1/status?regions=32"

# потік змін (-N — без буферизації)
curl -N -H "Authorization: Bearer $TOKEN" "https://alerts.example.com/api/v1/stream?regions=32"
// Node 18+ або браузер з токеном у заголовку (fetch уміє потоки)
const r = await fetch("https://alerts.example.com/api/v1/stream?regions=32", {
  headers: { Authorization: `Bearer ${TOKEN}` },
});
const reader = r.body.pipeThrough(new TextDecoderStream()).getReader();
let buf = "";
for (;;) {
  const { value, done } = await reader.read();
  if (done) break;                        // обрив — перепідключіться
  buf += value;
  let i;
  while ((i = buf.indexOf("\n\n")) >= 0) {
    const block = buf.slice(0, i); buf = buf.slice(i + 2);
    const ev = /^event: (.*)$/m.exec(block)?.[1];
    const data = /^data: (.*)$/m.exec(block)?.[1];
    if (ev === "snapshot") render(JSON.parse(data).regions);
    if (ev === "update") update(JSON.parse(data).region);
  }
}

// ESP8266 (ESP-12F, NodeMCU, Wemos D1 mini). Плата: esp8266 core 3.x; бібліотека ArduinoJson 7.
// Опитування стану раз на 15 с — найнадійніше для ESP8266 (мало пам'яті під TLS).
#include <ESP8266WiFi.h>
#include <ESP8266HTTPClient.h>
#include <WiFiClientSecureBearSSL.h>
#include <ArduinoJson.h>

const char* WIFI_SSID = "…";
const char* WIFI_PASS = "…";
const char* URL    = "https://alerts.example.com/api/v1/status?regions=37";
const char* TOKEN  = "ac_…";
const char* REGION = "37";

BearSSL::WiFiClientSecure tls;

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  while (WiFi.status() != WL_CONNECTED) delay(250);
  tls.setInsecure();   // для початку; надійніше — setTrustAnchors() з коренем ISRG Root X1
                       // (тоді потрібен точний час: configTime(0, 0, "pool.ntp.org"))
}

void poll() {
  HTTPClient http;
  http.setTimeout(10000);
  if (!http.begin(tls, URL)) return;
  http.addHeader("Authorization", String("Bearer ") + TOKEN);
  const char* keys[] = {"Retry-After"};
  http.collectHeaders(keys, 1);
  int code = http.GET();
  if (code == 200) {
    // фільтр: розбираємо лише потрібні поля — економить оперативну пам'ять
    JsonDocument filter;
    filter["stale"] = true;
    filter["regions"][REGION]["state"] = true;
    filter["regions"][REGION]["level"] = true;
    JsonDocument doc;
    if (!deserializeJson(doc, http.getStream(), DeserializationOption::Filter(filter))) {
      bool stale = doc["stale"];
      const char* state = doc["regions"][REGION]["state"] | "none";   // active | partial | none
      const char* level = doc["regions"][REGION]["level"] | "";       // red | yellow | unknown
      Serial.printf("%s %s%s\n", state, level, stale ? " (stale)" : "");
      // showState(state, level, stale);
    }
  } else if (code == 429) {
    int wait = http.header("Retry-After").toInt();
    http.end();
    delay((wait > 0 ? wait : 30) * 1000UL);
    return;
  } else {
    Serial.printf("HTTP %d\n", code);   // 401 — токен; від'ємне — мережа/TLS
  }
  http.end();
}

void loop() {
  if (WiFi.status() == WL_CONNECTED) poll();
  delay(15000);
}
